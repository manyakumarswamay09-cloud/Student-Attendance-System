# Student Attendance System

## Project Description
Student Attendance System is a Java-based application used to manage student attendance digitally.
It helps to register students, mark attendance, search student records, and generate attendance reports.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Data Structures and Algorithms
- JSON

## Main Features
- Student Registration
- Attendance Marking
- Student Search
- Attendance Percentage
- Sorting and Reports
- Data Storage

## Data Structures Used
- HashMap
- Queue
- ArrayList
- Searching
- Sorting

## How to Run
1. Download or clone this repository.
2. Open `App.java` in a Java IDE or VS Code.
3. Compile and run the program.
